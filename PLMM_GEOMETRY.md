# Геометрия магнитной системы ПЛМ-М

В конфигурации расчёта включена модель `plmm_assembly`. Для 2-D FDFD используется осесимметричное усреднение, а полноценное 3-D поле каспов рассчитывается отдельной командой.

Поле кругового витка рассчитывается через полные эллиптические интегралы первого и второго рода. Формулы проверяются независимым численным интегрированием закона Био–Савара в `tests/test_magnetic_system.py`.

## Зафиксированные данные установки

- число постоянных магнитов — 8;
- осевая длина каждого магнита — 0,608 м;
- поперечное сечение каждого магнита — квадрат 0,018 × 0,018 м;
- соленоид разделён на две осевые секции;
- расчётная длина плазменной области в базовом конфиге — 0,808 м, включая условный участок сопла после 0,608 м;
- в конфигурации перечислены четыре режима `m=-1,0,1,2`, базовый режим — `m=1`.

## Что рассчитывает программа

Поле двух секций соленоида строится суммированием полей конечного набора круговых витков. Для каждой секции задаются осевые границы, число витков, ток, направление тока и число дискретных осевых слоёв.

Поле восьми магнитов строится интегрированием поля конечных дипольных элементов вдоль длины каждого магнита. В расчёте сохраняются длина и площадь квадратного сечения. Для 2-D FDFD поле усредняется по азимуту, поскольку основная FDFD-модель использует координаты `r,z`. Поле без усреднения доступно через `build_magnetic_field_3d` и команду `magnetic_3d.py`.

После построения фоновые поля `B_r(r,z)` и `B_z(r,z)` передаются в локальный тензор Стакса. Радиальная задача дисперсии использует профиль поля на выбранном сечении `solver.dispersion_z_m`, а не постоянное значение `B0`.

## Параметры, которые ещё требуется уточнить измерением

В предоставленных данных не указаны радиус центров магнитов, их азимутальные углы, направление намагничивания, полярности, остаточная индукция и токи секций соленоида. В базовой конфигурации эти параметры вынесены в YAML и имеют начальные значения для запуска модели.

Включена калибровка поля соленоида по `plasma.B0 = 0.03 Тл`. Она нужна потому, что численное значение тока и число витков секций пока не подтверждены. Поле постоянных магнитов добавляется с коэффициентом `magnets.field_scale`.

Для окончательного расчёта необходимо заменить в `config.yaml` следующие поля измеренными данными:

```yaml
plasma:
  magnetic_field:
    solenoid:
      radius_m: ...
      sections:
      - z_start_m: ...
        z_end_m: ...
        turns: ...
        current_A: ...
      - z_start_m: ...
        z_end_m: ...
        turns: ...
        current_A: ...
    magnets:
      center_radius_m: ...
      azimuths_deg: [...]
      polarities: [...]
      magnetization_direction: radial
      remanence_T: ...
```

Значения `length_m: 0.608`, `cross_section_m: 0.018`, `count: 8` и две секции соленоида уже установлены согласно актуальному описанию установки.

## Запуск

Проверка конфигурации без решения:

```bash
python main.py --config config.yaml --dry-run
```

Полный расчёт одного набора параметров:

```bash
python main.py --config config.yaml
```

Сканирование дисперсии для пяти частот в режиме `m=1`:

```bash
python run_all.py --config config.yaml --no-fields
```

Полный 3-D расчёт магнитного поля каспов:

```bash
python magnetic_3d.py --config config.yaml
```

Вариант с CUDA использует `config_cuda.yaml`, где включён CuPy и итерационный GMRES:

```bash
python run_all.py --config config_cuda.yaml --modes 1 --frequencies 5 7.5 9.8 12 15 --no-fields
```

В результатах сохраняются карты `B_r`, `B_z`, радиальные профили, выбранные радиальные собственные моды и параметры использованной магнитной геометрии.

Поля секций соленоида, координаты магнитов, полярности, положение антенны и параметры сопла в базовой конфигурации имеют статус `provisional`, пока не заменены измеренными значениями. Программа сохраняет относительную проверку `div(B)` в метаданных запуска.
